Upgrade to .NET 8, Cross-Platform Support, and Publish Scripts

Migrated core applications (Werewolf Node, Werewolf Control, Database, Shared, TcpFramework, ClearUpdates, BuildAutomation) to use the new SDK format targeting `net8.0`. Cleaned up `packages.config` and migrated to `PackageReference`, including bumping EntityFramework to a compatible version. Replaced Windows-only registry configuration with Environment Variables. Mocked out legacy Windows Forms charting logic from `DevCommands.cs` to prevent Linux compile failures. Updated file path separators from explicit backslashes (`\\`) to use `Path.Combine()` for cross-platform compatibility. Created `publish.bat` and `publish.sh` for easy CI/CD integration generating both framework-dependent and self-contained builds for `win-x64` and `linux-x64`. Removed legacy Web modules that broke `BuildAutomation`. Website projects were explicitly excluded from the scope of this refactor as per user instructions.
